# 🚀 ANTIGRAVITY ALL-IN-ONE YOUTUBE CREATOR AI STUDIO
### ગુજરાતી યુટ્યુબ ક્રિએટર સ્ટુડિયો (Gujarati YouTube Creator AI App)

A complete, production-ready, mobile-friendly **All-in-One YouTube Creator AI Studio** built specifically for Gujarati content creators. Manage your YouTube channel, analyze 48-hour views & authorized revenue, discover trending topics with evidence & transparent scoring, generate one-click YouTube SEO packages, design 16:9 thumbnails on high-contrast canvas, write long-form video scripts sequentially without cutoffs, and chat with a built-in ChatGPT AI assistant directly from a single unified dashboard.

## 🛠️ Technology Stack & Architecture

- **Backend**: Node.js & Express.
- **APIs**:
  - `googleapis`: Google OAuth2, YouTube Data API v3, YouTube Analytics API v2.
  - `openai`: Official OpenAI SDK (`gpt-4o`, `gpt-4o-mini`, `dall-e-3`).
  - `rss-parser`: Live Google Trends India RSS & Gujarati media feeds.
- **Database**: Persistent atomic JSON database (`data/database.json`) storing settings, auth tokens, scripts, topics, and chat histories.
- **Frontend**: Vanilla HTML5, CSS3, and ES6+ JavaScript modules.
  - Typography: Google Fonts `Outfit` (UI numbers) and `Noto Sans Gujarati` (clean Unicode Gujarati).
  - High-DPI HTML5 Canvas (1280 × 720) for thumbnail rendering and export.
  - Mobile-first responsive design with bottom navigation bar for mobile and sidebar for desktop.
  - Android-compatible clipboard utility (`navigator.clipboard` + fallback).

## 🚀 Quick Start Guide

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables (Optional)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Fill in your Google OAuth and OpenAI credentials, or configure them directly inside the app's **Settings** screen.

Verifies topic scoring algorithms, word count calculators, SEO generator schemas, thumbnail concepts, and atomic database persistence.

### 4. Start the Application
```bash

```
Open **[http://localhost:5000](http://localhost:5000)** in your browser or phone.

## 🔑 How to Setup Google OAuth (YouTube APIs)

1. Go to [Google Cloud Console](https://console.cloud.google.com).
2. Create a new project named `YouTube Creator AI Studio`.
3. In **APIs & Services > Library**, search and **ENABLE**:
   - **YouTube Data API v3**
   - **YouTube Analytics API**
4. In **OAuth Consent Screen**:
   - User Type: **External**.
   - App Name: `Creator AI Studio`.
   - Add scopes: `.../auth/youtube.readonly` and `.../auth/yt-analytics.readonly`.
   - Add your Google account under **Test users**.
5. In **Credentials > Create Credentials > OAuth Client ID**:
   - Application type: **Web application**.
   - Authorized redirect URIs: `http://localhost:5000/api/auth/google/callback`.
6. Copy the **Client ID** and **Client Secret** into the app's **Settings** page and click **Save Settings**.
7. Click **🔴 Connect My YouTube Channel** on the Home dashboard!

## 🤖 How to Setup OpenAI API Key

1. Go to [OpenAI Platform API Keys](https://platform.openai.com/api-keys).
2. Click **Create new secret key** and copy it (`sk-...`).
3. In the app, navigate to **Settings** (`⚙️`).
4. Paste the key into **OpenAI API Key**, select `GPT-4o`, and click **Save Settings**.
5. The built-in ChatGPT Creator Assistant, Script Writer, and SEO Generator will immediately utilize GPT-4o!
*(Note: If no key is configured, the built-in intelligent Gujarati Creator Engine provides full local responses seamlessly).*
